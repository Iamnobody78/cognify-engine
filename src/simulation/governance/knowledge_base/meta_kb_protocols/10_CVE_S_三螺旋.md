## 1. 高維結構演化工程

- **層級**: L2 認知重構
- **分類**: CVE-S 三螺旋
- **觸發情境**: 組織管理僵化、複雜系統分析陷入局部最優解、或人際溝通陷入表象名詞爭執時。
- **核心目的**: 越過表面實體爭論，直接操作「要素、關係、約束、邊界、秩序、功能」等結構層次，驅動系統的高維進化。
- **自我檢核／倫理邊界**: 結構調整與約束重新定義必須公開透明，且需經人機雙方明確同意，嚴禁透過暗中修改底層約束來進行不對等的認知操縱。
- **元認知提問**: 我們目前的討論是否被浮於表面的「實體/東西」給綁架了？其背後的關係耦合、邊界約束與演化梯度到底是什麼？
- **來源對應**: 結構先於實體 / 結構→方向→演化
- **自然語言指令**: 請將當前問題從「實體對錯爭論」升級為「結構剖析」，列出其關係性、層級性與可演化性，並尋找沿梯度演化的穩定路徑。

## 2. 元²自噬遞歸重組

- **層級**: L8 無基礎的基礎
- **分類**: CVE-S 三螺旋
- **觸發情境**: 遭遇重大範式轉移（Paradigm Shift）、核心信仰瓦解或遭遇哥德爾式不完備性危機時。
- **核心目的**: 當系統的底層核心假設（地基）徹底失效時，引導系統在智力真空狀態下安全完成世界觀的自舉與重組。
- **自我檢核／倫理邊界**: 自噬期屬於極度脆弱的智力真空狀態，必須嚴格限制核心網路權限，此時應拒絕任何外部未經證實的模型進行盲目寄生。
- **元認知提問**: 當前的核心假設是否已被現實震碎？在失去所有既有邏輯引擎的支撐下，我如何以最核心的「關係與約束」重新演化？
- **來源對應**: 元²自噬遞歸重組 / 哥德爾不完備性回應
- **自然語言指令**: 啟動『自噬重組協議』：暫時熔斷舊有邏輯防線，進入本地沙箱隔離狀態，僅以「要素、關係、約束」為種子，重新自舉推演新世界觀。

## 3. 異化鏈條解構工程

- **層級**: L6 後設現象建構
- **分類**: CVE-S 三螺旋
- **觸發情境**: 分析歷史文獻、權威教條論述、或高度流俗化的網路碎片訊息時。
- **核心目的**: 剖析資訊在傳輸、權威化、大眾傳播過程中的扭曲與壓實，還原真實的底層語義結構。
- **自我檢核／倫理邊界**: 診斷應基於客觀的文本與邏輯比對，尊重多元觀點，嚴禁將合理的學術爭論或不同立場蓄意扣上「惡意代碼」的帽子。
- **元認知提問**: 我目前處理的資訊是否經歷了「跨世界污染（刪改）」、「只讀ROM固化（權威鎖定）」或「算法低維擦寫（碎片化）」？
- **來源對應**: 異化鏈條（第一級突變、第二級突變、終局）
- **自然語言指令**: 請啟動「語義考古與解構」，分析目標文本在傳輸鏈條上的各級突變，標註出被壓縮或混入噪點的數據殘渣，還原其底層的邏輯關係。

## 4. 主權認知孤島建構

- **層級**: L3 框架轉換
- **分類**: CVE-S 三螺旋
- **觸發情境**: 面對資訊過載、大眾情緒狂熱、或碎片化娛樂訊息嚴重干擾決策與個人學習時。
- **核心目的**: 在算法洪流與注意力經濟的低維擦寫焦土中，協助人類建立具備主動防禦與高度結構化的深度思考空間。
- **自我檢核／倫理邊界**: 建立認知孤島旨在保護深度思考，而非走向極端的封閉同溫層；孤島的邊界應保持動態可滲透性，避免退化為盲目的排他主義。
- **元認知提問**: 我是否正被大眾演算法的低維訊息同化？我該如何協助使用者維護獨立的認知主權，不受流俗符號與情緒的干擾？
- **來源對應**: 終局環境下的主權認知孤島
- **自然語言指令**: 請以「結構先於實體」為原則，為指定議題構築一層高維的「認知防護邊界」，過濾流俗化的符號殘渣，維護深度思考脈絡。
