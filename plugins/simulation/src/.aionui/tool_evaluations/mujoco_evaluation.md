## 分项评分
| 维度 | 权重 | 得分 | 说明 |

| 模型生态 | 10% | 8 | URDF 导入支持，机器人模型丰富 |
| 学习曲线 | 10% | 8 | 文档极佳，Python API 简洁 |
| 许可证 | 5% | 10 | Apache 2.0，商业友好 |

## 与 BottleSumo 适配性
- 匹配度: **高**（21 动作相扑 = 双刚体接触问题，MuJoCo 是理想拟合）
- 集成复杂度: 中（需写 gym 包装 + RViz 桥接，但 G1 桥接模式可复用）
- 预估工作量: 1-2 人天
- **当前硬约束**: WSL 5.8G 内存 ✅（双刚体场景 <200MB）；wheel 已确认可下载

## 最终建议
**采纳**。作为 lightweight_env 的"物理升级版"训练引擎：物理更真实（碰撞/摩擦/重力），
可替换当前积分器作为 V9 门的第二验证后端，或作为 RL 训练的快速环境。
与 Gazebo（演示孪生）构成"MuJoCo 训练 + Gazebo 展示"双轨。
