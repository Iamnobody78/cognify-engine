## 1. 目标

1. 将 3 个 Notion 链接（人机协作协议 + MMCE 框架 + .aionui 记忆库设计）注入研究引擎作为 R1 输入

3. 产出对应协议/目录方案的可执行代码或架构资产
4. 验证研究引擎对多种输入类型的泛化能力

## 2. 验收标准

| 标准 | 目标 |
|------|------|
| 输入泛化 | `--input-type notion` 全链路 gates PASS |

| 诚实披露 | CSR 墙 + 元回退记录 |
