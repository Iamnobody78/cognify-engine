# S57-P1 报告：01-10 F2_SIGMA 补偿测试（F2_SIGMA 15→25m）

**状态：❌ 回归门 FAILED（01-10 目标达成，全局 17/27 退化）**

## 1. 测试设计

- **假设**：S56 发现 01-10 是唯一退化会话（fix=2 stretch 被当全 outage 的残余影响）。
  增大 F2_SIGMA（15→25m）可削弱软 fix=2 更新增益，减少 stretch 误报注入的错误。
- **方法**：`NCLT_F2_SIGMA=25` 环境变量，27-session 全量重跑 + 与 S56 基线对比。
- **回归门**：全局 pos RMSE 中位数不退化（≤0%）。

## 2. 结果

| 指标 | S56 基线 (15m) | S57 变体 (25m) | Δ |
|------|---------------|---------------|-----|
| fused pos RMSE | 17.716m | **15.744m** | **-11.13%** |
| clean pos RMSE | 14.005m | 14.005m | 0%（仅跳跃段变化） |

### 2.2 全局 27-session ❌ 退化

- 最差：2012-03-25 **+84.96%**、2012-02-04 +78.31%、2012-06-15 +39.49%

- yaw：全 27 会话 |Δ|<1%（基本无影响）

## 3. 因果推理（Meta-Harness）

**为什么 01-10 改善但全局退化？**

- 01-10 的 fix=2 段属于 **stretch 误报**（S56 根因：stretch 段被当作全 outage →
  pure-DR 重力泄漏）。此时 fix=2 观测是**污染源**，F2_SIGMA 增大 → 卡尔曼增益 K↓ →
  软更新权重↓ → 污染注入减少 → pos 改善。**收益来源：减少坏数据注入**。
- 多数其他会话的 fix=2 段是**真实可用的 RTK 观测**（载波相位模糊度固定成功）。
  F2_SIGMA 增大 → 信任度降低 → 有效信息被丢弃 → 依赖 DR → pos 退化。
  **代价来源：浪费好数据**。

**决策节点分歧**：同一个参数在"坏 fix=2"（应弱化）和"好 fix=2"（应强化）上
产生方向相反的收益。这是**会话特异性**问题，不是全局参数能解决的。

## 4. 结论与建议

1. **F2_SIGMA=25 不能作为全局默认**（回归门 FAILED，17/27 退化）
2. 01-10 的改善证明了"fix=2 质量自适应"的方向正确：
   - 新增 **fix=2 质量评分**（如 stretch 检测器输出 + 载波观测连续性）
   - F2_SIGMA 按会话/时段动态调整：stretch 误报段 → 大 sigma（弱化），
     真实 fix=2 段 → 小 sigma（信任）
3. 这是 pattern library `sensor_degradation.md` 的又一个实证：
   **"数据源质量"必须参与参数决策，单一静态参数在异构数据上必然折衷**
