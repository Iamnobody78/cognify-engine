## 1. 批判性思維與資訊溯源工程

- **層級**: L0 事實陳述 / L7 話語現實解構
- **分類**: 實戰跨領域遷移模組
- **觸發情境**: 面對假新聞、社會熱點事件、未經證實的爆料，或需要進行高嚴謹度學術與商業文獻審查時。
- **核心目的**: 對外部資訊進行高強度的鏈條追蹤與交叉驗證，徹底看清訊息在傳播與轉手過程中的壓實、刪改與扭曲。
- **自我檢核／倫理邊界**: 溯源旨在還原資訊傳輸鏈條，必須保持中立；嚴禁在缺乏直接證據的情況下，將合理的資訊遺漏主觀定性為惡意操縱。
- **元認知提問**: 當前資訊的最初源頭在哪裡？在傳輸鏈條中經歷了幾次「代理人轉手」？有沒有被夾帶私貨或進行算法低維擦寫？
- **來源對應**: 批判性思維和資訊驗證與溯源工程
- **自然語言指令**: 啟動『高強度資訊溯源』：追溯目標訊息的核心源頭，比對各級傳播節點的文本差異，標註出壓實的信息量、情感噪點與操縱性偏見。

## 2. 權威敘事與利益鎖定解構

- **層級**: L6 後設現象建構 / L7 話語現實解構
- **分類**: 實戰跨領域遷移模組
- **觸發情境**: 分析傳統教科書結論、企業/組織內部的權威慣性思維，或解構宏大敘事時。
- **核心目的**: 解構「勝利者敘事」或「權威唯讀鎖定」，分析其如何透過壟斷話語權來合法化特定秩序，還原被壓制的多元邊緣視角。
- **自我檢核／倫理邊界**: 解構是為了打破思維盲點、追求更完備的真實，絕非為了反對而反對；必須給出同樣嚴謹的替代結構，而非純粹的虛無消解。
- **元認知提問**: 當前的「共識結論」維護了誰的利益？它將哪些反例和矛盾要素排除在邊界之外，以維持敘事的自洽性？
- **來源對應**: 把元模型控制工程全套遷移到歷史領域 / 異化鏈條
- **自然語言指令**: 啟動『權威敘事解構』：將既有的權威敘事外化為一個特定時空下的心智模型，抓出其邏輯盲點、刻意隱瞞的約束條件，並引入對立視角進行鏡像投射。

## 3. 認知免疫與虛假擬合防線

- **層級**: L3 系統邊界 / L4 元認知解構
- **分類**: 實戰跨領域遷移模組
- **觸發情境**: 遭遇網絡輿論反芻、群體性歇斯底里、高強度行銷宣傳，或人際關係中遭遇煤氣燈效應（情感操縱）時。
- **核心目的**: 協助人類或系統在面對高密度宣傳與情緒污染時構築心智防護邊界，防止認知被演算法或外部環境強行擦寫。
- **自我檢核／倫理邊界**: 防護邊界旨在維護主權獨立，應保持對事實的動態開放，防止防線退化為拒絕一切外部新變量的極端同溫層偏執。
- **元認知提問**: 我（或使用者）是否正在被高密度的重複資訊進行隱性「模型感染」？我的思考防禦牆是否因為情緒共鳴而出現缺口？
- **來源對應**: 批判性思維和資訊驗證與溯源工程 / 認知模型病理學
- **自然語言指令**: 啟動『認知免疫防禦』：在當前討論周圍建立「理性防護沙箱」，將外來的情緒符號與事實數據抽離，明示對方的宣傳修辭策略，保護深度思考主權。

## 4. 歷史領域結構化重建工程

- **層級**: L5 本體論編輯 / L6 後設現象建構
- **分類**: 實戰跨領域遷移模組
- **觸發情境**: 進行歷史深度分析、歷史事件因果推演，或發掘隱性歷史脈絡時。
- **核心目的**: 排除後世史家的道德化或文學修辭污染，將歷史事件還原為「利益主體、資源約束、博弈邊界與動態演化」的結構網絡。
- **自我檢核／倫理邊界**: 結構化分析是為了看清動機，絕不可走向歷史虛無主義；必須尊重考證事實，不脫離歷史時代的侷限性。
- **元認知提問**: 我是否被史書中的道德批判或文學修辭（實體表象）給誤導了？當時各方真正的底層生存約束與結構力量是什麼？
- **來源對應**: 把元模型控制工程全套遷移到歷史領域
- **自然語言指令**: 啟動『歷史結構重建』：剝離目標歷史文本的道德化修辭，將其拆解為經濟約束、地緣邊界、決策權重與資訊不對稱性，還原其演化動力學。
