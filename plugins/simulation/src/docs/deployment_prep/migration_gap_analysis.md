# 仿真→真机迁移差距分析 (BS-DEPLOY-PREP A2)

> 日期: 2026-08-11 | 依据: 赛规 PDF (高級組) + bottlesumo-pi 仿真架构

## 仿真侧现状 (基线)

| 模块 | 文件 | 当前实现 |
|------|------|----------|
| 环境 | `governance/meta_harness/variants/lightweight_env.py` | 2D 圆形擂台, gym 接口 |
| 观测 | 同上 | **7 维 obs**: `[edge_L, edge_R, edge_F, edge_B, opp_dist, opp_angle, speed]` (0-1 归一化) |
| 规则引擎 | `simulation_rules.abdl` | 决策规则 (高级组行为) |
| 治理 | agent-governance-v2 | 裁决/审计层 |
| 训练 | PyTorch RL | heuristic/DQN/NanoQNet |

## 差距清单 (≥5 项, G2 门禁)

| # | 差距 | 类别 | 仿真侧 | 真机侧 | 优先级 |
|---|------|------|--------|--------|--------|
| GAP-1 | **感知来源** | 感知 | 理想化 obs 直接赋值 | 需 LiDAR 点云 → 7 维 obs 换算 | P0 |
| GAP-2 | **边缘检测** | 感知 | 数学计算 (r > 0.325) | 台板边缘距离连续测量 (胶纸缝隙突变检测) | P0 |
| GAP-3 | **对手定位** | 感知 | obs[4] opp_dist 直接注入 | 点云聚类 → 最近障碍物距离/方位 | P0 |
| GAP-4 | **执行控制** | 执行 | action(int) → 速度设定 | PWM 电机驱动 (需 PID/死区补偿) | P0 |
| GAP-5 | **时间基准** | 环境 | 仿真时钟 | 真实时钟 (120s 回合) + 3s 停留判定 | P1 |
| GAP-6 | **水樽物理** | 环境 | 刚体碰撞模型 | 真实水樽 (2L 樽, ~1L 水, 晃动) | P1 |
| GAP-7 | **场地未知变量** | 环境 | 固定参数 | 台板颜色/胶纸/水樽色带/支撑高度当天公布 | P1 |
| GAP-8 | **传感器噪声** | 感知 | 无噪声 | LiDAR 测距噪声 (±2cm) / 丢帧 | P2 |
| GAP-9 | **合规约束** | 系统 | 无物理约束 | ≤1kg / ≤30cm / ≤2控制器 / ≤3电机 / ≤14V | P0 |

## 结论

- **9 项差距**识别 (≥5 达标), 其中 P0 五项构成迁移核心: 感知→执行闭环
- LiDAR 解决 GAP-1/2/3/7/8 (测距免疫颜色/光照变化) — 与赛规"传感器不限"契合
- 治理引擎 (agent-governance-v2) 保持仿真/真机一致, 作为策略决策层复用
