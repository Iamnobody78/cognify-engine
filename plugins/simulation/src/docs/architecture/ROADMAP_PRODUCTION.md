## 4. 每阶段演进原则

1. **先治标，再治本，后引领**：v2.x 解决"能不能用"→ v3.0 解决"好不好用"→ v4.0 回答"能走多远"
2. **每 Sprint 至少处理 1-2 个 P0/P1**（ARCH-COMPLETE 元提示词强制）
3. **每项补全三同步**：代码 + 文档 + 测试（GATE 失败不声称完成）
4. **版本兼容**：v2.x 期间保持 SQLite 默认可用；API 变更必须过 E2E 9/9
5. **证据链**：每项补全附带 commit hash + 测试结果（TRACE-AGENT 协议）
