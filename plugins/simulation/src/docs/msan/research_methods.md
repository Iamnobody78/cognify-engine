## 1. 四维度全阴性排查模板（S53 归档）

**适用**: 评估指标退化，且怀疑数据源质量异常时。先排除数据供给层，再谈融合层。

**核心思想**: 不猜——把所有可能影响指标的信号路径逐层、量化地检查一遍，
全部阴性则退化必在融合层/观测几何层，数据源假设正式关闭。

**四维度顺序**（由原始到消费端）:

| 维度 | 检查内容 | 工具示例 |
|---|---|---|
| ① IMU 原始信号 | 采样间隔中位数、gyro/acc 统计、零偏均值、dropout 率 | `nclt_imu_signal_check.py` |
| ② 观测质量 | fix 率、误差分布 p50/p95、抖动、速度合理性 | `nclt_rtk_quality2.py` |
| ③ 真值质量 | 跳变计数、dropout、姿态角合理性（roll/pitch 量级） | `nclt_truth_quality.py` |
| ④ 消费端信号 | 估计器实际使用的派生信号（如窗口差分航向）vs 真值误差 | `nclt_hdg_noise_batch.py` |

**判定规则**:
- 四维度全部与健康 session 同区间 → **数据源假设关闭**，退化定性为融合层真实变异
- 任一维度异常 → 定位到具体信号路径，进一步追查
- 注意：同一指标用不同维度交叉验证（如 IMU 正常但 yaw 退化 → 查航向伪观测，而非重复查 IMU）

**实战案例**: S53 11-16/17 双日退化 → 四维度全阴性 → 数据源假设关闭，
位置域优化解冻（S54 立项依据）。相邻 session 核实（真实前邻/后邻）亦属此模板——
"想当然的相邻日期"必须先验证存在性。

## 2. Meta-Harness 变体扫描模板（S54 归档）

**适用**: 任何可参数化的信号处理/融合模块的超参数寻优。

**核心思想**: 不手工调参——定义候选变体空间 → 固定评估集全量回测 →
帕累托支配筛选最优配置。全局最优非局部最优。

**流程**:

```
1. 定义变体空间: 每个可调参数一个维度，网格/候选点枚举
   - 例: (RTK_ERR_GATE, DR_SIGMA) × {v1..v4} + legacy 基线
2. 固定评估集: 全量 session（27），不许挑子集
3. 全量回测: 每个变体 × 每个 session，输出统一指标集
   - 关键指标: 目标域中位数/p90/max + 邻近域最大偏移（防串扰）
4. 帕累托支配筛选: 变体 A 支配 B ⟺ A 在所有指标上不劣于 B 且至少一项严格优于
5. 裁决: 唯一严格支配基线者入选；无严格支配者时用加权目标选前沿点
6. 诚实标注: 被淘汰变体的失败模式要记录（如 v1 过度降权 → 03-31 +160m）
```

**关键设计原则**:
- **邻近域零影响是硬约束**: 优化位置域时姿态域（yaw/roll）必须零偏移——
  指标表必含"最大跨域偏移"列，变体使任何 session 姿态偏移 >1° 即淘汰
- **极端值治理优先于均值**: 重尾分布下 p90/max 往往比中位数更能体现优化价值
- **失败案例与成功案例同等重要**: v1 的灾难（+160m）证明了 gate 下限的物理意义
- **基线可复现**: 每个优化必须保留 legacy 开关（`NCLT_EKF_LEGACY=1`）精确复现基线

**实战案例**: S54 位置域优化 → 5 变体 × 27 session 全量回测 → v3 (GATE=12/DR=0.05)
唯一严格支配 legacy → pos 中位数 -2.6%、极端值 -47.2%、姿态域偏移 ≤0.17°。
05-26 标志性案例 840m→22m（-97%）。
