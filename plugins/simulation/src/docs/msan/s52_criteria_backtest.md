## 判据定义

| 判据 | 定义 | 说明 |
|---|---|---|
| OLD（相对抑制比） | suppress_ratio < 0.20 | S50-S51 沿用的单一判据 |
| NEW（双判据） | (suppress_ratio < 0.20) **OR** (fused_yaw_rmse ≤ 21.6°) | 绝对残差作为低开环场景补充判据 |

**设计意图**（S51 统计发现）：融合残差由航向观测噪声底主导（~15-17°），与开环漂移无关
（corr(suppress, openloop) = -0.69）。低开环 session 的 20% 阈值低于噪声底 → 判据不可达。
绝对残差 ≤21.6°（S50 PM 原始目标）作为补充判据，标注"低开环场景，绝对残差健康"。

## ⚠️ 与 PM 预期的偏差：2012-11-17 仍为 FAIL（诚实报告）

PM 裁决预期"3 个 FAIL session 在补充判据下全部 PASS"。**实际回测仅 2 个 PASS，2012-11-17 保持 FAIL**：

| 指标 | 值 |
|---|---|
| 融合 yaw RMSE | **21.622°**（仅超 21.6° 阈值 0.02°） |
| 抑制比 | 0.2084（仅超 0.20 阈值 0.008） |
| 开环漂移 | 103.7°（**非低开环场景**） |
| yaw err p50 / p90 | **22.1° / 45.3°**（系统性偏差，非瞬态尖峰） |
| rtk_err p95 | 30.65 m（27 session 中质量偏差） |

**根因分析**：2012-11-17 与 2012-11-16（yaw 20.4°，27 个中第二差）为连续两天，
两者 yaw 残差显著高于其他 session（15-18° 区间）。其误差分布为**持续 ~22° 的系统性偏置**
（对比健康 session p50 3.8-13.4°），非低开环噪声底问题，亦非瞬态尖峰——指向该 session
存在持续性的航向观测偏差（RTK 差分航向质量下降）或真值（ms25_euler）质量下降。

**判定建议**：
1. 若执行 PM 判据（绝对残差 ≤21.6°）：2012-11-17 = **FAIL（边缘）**，PASS 率 26/27
2. 若考虑 0.02° 为数值边界：建议标注为"**边缘 FAIL（+0.02°）**"，不强行放行——保持判据刚性，
   但将 11-16/11-17 双日系统性偏差列为**后续调查项**（S52 遗留）

## 结论

- ✅ 判据演进有效性确认：2 个低开环 FAIL 通过补充判据合理转 PASS（PASS 率 88.9% → 96.3%）
- ⚠️ PM 预期修正：3 → 2（2012-11-17 为真实边缘 FAIL，非判据问题）
- 📌 新判据正确识别了"低开环噪声底"与"真实退化"的区别：01-15/01-22 属前者（应放行），
  11-17 属后者（应 FAIL）——双判据设计本身有效，其价值恰在于不放过 11-17 这类真实退化
