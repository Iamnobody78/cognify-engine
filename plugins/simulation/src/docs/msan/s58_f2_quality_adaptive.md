## 2. 根因：P 爆炸使 sigma 拨盘失效 (机制级发现)

### 2.1 为什么 sigma 自适应不够 (S57 教训)

S57 尝试 session/全局 sigma 25m 削弱 fix=2 陈旧坐标拉扯：**01-10 改善 (−11.1%) 但 17/27
退化 (median +3.49%)，03-25 爆雷 +84.96%。** 原因不在 sigma 本身，而在协方差结构：

| session | 退化段内 P_pos 峰值 | sigma 15 vs 25 的 K | 结论 |
|---------|--------------------|--------------------|------|
| 01-10 | 8,344 m² (σ=91m) | 0.974 vs 0.930 | sigma 拨盘可用 → 25 帮助 |
| 03-25 | **1.78e6 m² (σ=1,335m)** | 0.999 vs 0.999 | **K≈1 双配置全量钉死 → sigma 拨盘失效** |

**根因链**: 传播矩阵 F[0:3,3:6]=I（速度→位置耦合）使 ΦPΦᵀ 在长退化段对 P_pos 产生
**二次方增长**（03-25 的 1.78e6 m² 是 F2_STALE_RATE 线性项 0.25 m²/s 贡献的 ~100 倍）。
P 一旦爆炸，K = P/(P+σ²) ≈ 1，**与 sigma 取值无关**——软更新变成对陈旧冻结坐标的全量钉死，
sigma 拨盘彻底失效。

### 2.2 为什么移除 fix=2 处理不可行 (F2_USE=0 反证)

01-10 F2_USE=0（无软更新、无 P 增长）= **28.065m**，比 S56 的 17.716m 还差 58%。
退化段无更新 → 速度重力泄漏失控 + 复收时 P 不足、Huber 门把大创新直接拒掉 → 状态长期无法
收敛。**fix=2 软处理是必要基础设施，问题只在"信任量"（P）过度膨胀。**

## 3. 机制修复：F2_PCAP 协方差封顶 (最小干预)

### 3.1 实现 (nclt_fusion_ekf.py, 新增 env `NCLT_F2_PCAP`)

```
退化段每步 P 增长后:
    if max(P[0,0], P[1,1]) > F2_PCAP_M²:
        sc = F2_PCAP_M / sqrt(max(...))
        P[0:2,:] *= sc;  P[:,0:2] *= sc     # 水平位置块联合缩放 (P <- D P Dᵀ)
```

- **联合缩放 (congruence)**: 同比例缩放水平位置行/列，保持 PSD；水平位置↔速度交叉项同步
  缩放 → 卡尔曼增益比 K_v = P_vp/(P_pp+R) 保持良态（只封顶 P_pp 会令速度增益爆炸，
  实测 01-10 发散至 238km，已修复）。
- **垂直通道 (idx 2) 排除**: 压缩 P[2,2] 会使垂直 kind=4 更新 (2·sig_h) 脱钩 → 垂直 DR
  漂移至 1980m (03-25 实测回归，已修复)。
- **速度/姿态/偏差协方差保持诚实**: 位置陈旧不降低 IMU 漂移不确定性。
- **默认 0.0 = S56 行为**；通过 env 选择 20/30/40m 进行参数扫描。

### 3.2 机制效果 (为什么 40m/25m 最优)

| 参数点 | K (kind=4) | 复收 3σ 门 | 关键 session 结果 |
|--------|-----------|-----------|------------------|
| S56 (无 cap, sig15) | 0.999 (长段) | ~4000m | 01-10: 17.72 / 03-25: 35.18 / 01-22: 11.74 |
| cap20/sig15 | 0.64 | 60m | 01-10: 10.84 / 03-25: 15.00 / **01-22: 14.43 (+23%)** |
| **cap40/sig25 (S58)** | **0.72** | **120m** | **01-10: 10.47 / 03-25: 11.69 / 01-22: 9.25 (−21%)** |

- **cap 40 同时满足两职**: (a) 退化段 K 封顶在 0.72 → 陈旧冻结坐标不再全量钉死；
  (b) 复收 3σ 门 = 120m → 吸收大位移复收创新（01-22 有 222m 位移 stretch，cap20 的 60m
  门需多步收敛造成 +23% 退化）。
- **sigma 25**: cap 使拨盘重新生效后，25m 的陈旧坐标去权 (S57 的 01-10 教训) 生效；
  对 02-23 保护场景 (cap20 时 σ25 略差) 在 cap40 下无副作用。
