## 1. 偏差特征报告 (T1)

### 1.1 结论先行

**02-23 的"系统性偏差"不是 RTK 跳变，而是 RTK fix=2 退化段被 fix>=3-only 门控当作全量失锁，
触发纯 DR 保持，导致 EKF 内部重力泄漏发散（速度 148-155 m/s，位置 ±10km），且长期无法恢复。**

### 1.2 根因链 (三源独立验证)

| # | 环节 | 证据 | 工具 |
|---|------|------|------|
| 1 | RTK fix 3→2 降级 | epoch 1361644981-5131 出现 154s fix=2 连续行，坐标**完全冻结** (0.738142973/-1.461079224)，trk/spd=nan | nclt_s56_rtk_gap_check.py |
| 2 | 门控误判为失锁 | 代码 fix>=3-only 调度 -> dr_hold_regions 含 (1361644977.1, 1361645131.1) 154s 区域 | nclt_fusion_ekf.py log |
| 3 | 纯 DR 重力泄漏 | 150s 无更新: 名义速度 2.5 -> 148-155 m/s; 泄漏 = 9.81·dθ_h (姿态误差 ~5.7°), 位置二次积分 -> +10km | s56_debug.log (t=4979→5129 跳变) |
| 4 | 协方差爆炸锁死恢复 | P_pos 膨胀至 σ~1100m -> chi2 门恒过 -> 更新无法约束状态 -> 发散持续 1400s+ | NCLT_F2_TRACE 输出 |
| 5 | 复收跳变 | fix=3 复收点距冻结坐标 116m (陈旧 vs 真值) | nclt_s56_rtk_gap_check.py |

### 1.3 fix=2 的系统性统计 (27-session 审计)

- **占比**: 全部 session 的 6.5-17.9% RTK 行是 fix=2（均值 ~13%）
- **最长连续段**: 55-348s（2013-04-05: 315s, 2012-11-04: 348s）
- **物理性质**: 退化段内接收机输出"冻结/陈旧"坐标 (hold-last-fix)，IMU 显示 rover 原地旋转
  (gyro ±29°/s, |acc|≡9.81) 或缓慢机动 -> 冻结坐标早期近似真值，后期陈旧

> **关键教训 (→ RULE-MC-011)**: 传感器退化段 ≠ 失锁。退化数据带信息，直接丢弃并把退化段
> 当纯 DR 保持是灾难性的——NCLT 中这是**系统性**模式而非偶发异常。

## 2. 检测逻辑产出 (T2)

### 2.1 检测特征 (可操作规则候选)

```
检测特征 = fix 降级 (fix==2) + 连续相同坐标 (冻结/陈旧) 持续 > F2_MIN_GAP(2s)
```

### 2.2 补偿机制 (nclt_fusion_ekf.py S56 参数块)

| 参数 | 值 | 机制 |
|------|-----|------|
| BIAS_EXCL / JUMP_DMAX | on / 40m | 位移判据跳变排除 (both/OR 邻居触发) |
| **F2_USE** | on | fix=2 软位置更新启用 (kind=4) |
| F2_SIGMA | 15m | fix=2 软更新 sigma (Huber 保护) |
| F2_STALE_RATE | 0.5 m/s/√s | 退化段 P_pos 增长 (使软更新高增益) |
| F2_MIN_GAP | 2s | 仅无 fix>=3 邻域时调度 (正常操作位级不变) |
| F2_VCLAMP | 20 m/s | 传播后速度抗饱和 (物理上限) |

### 2.3 机制 (为何有效 — 三源验证)

1. 退化段 P_pos 自然/主动膨胀 -> fix=2 更新 K~0.84 高增益 -> **钉住冻结坐标**
2. 交叉协方差抑制姿态漂移 -> 重力泄漏从 1 m/s² 降至 0.1 m/s²
3. 复收时 Huber + 高增益把状态拉回真值 (速度 148 -> 0.41 m/s, 位置平滑过渡)

(15.4m)。+2.3m 绝对量极小且仍是最准 session，来源为 fix=2 陈旧坐标对位置的中等强度拉扯
