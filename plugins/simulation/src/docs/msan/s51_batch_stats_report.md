## 3. 统计显著性分析（T3 核心）

### 3.1 噪声底定律（本批处理最重要的统计发现）

```
corr(fused_yaw, openloop)  = +0.31   （融合残差几乎与开环漂移无关）
corr(suppress, openloop)   = -0.69   （开环漂移越大，抑制比越好）
```

**解释**：融合残差由**航向伪观测噪声底主导**（中位 8.2°、p90 19.9°，来自 30 s 窗 RTK 差分航向 + 非完整约束），与开环漂移量无关。因此：

- 开环漂移 > 100° 的 session（24 个）：目标 20% = 20-23°，高于噪声底 → 抑制比稳定 0.15-0.18 ✅
- 开环漂移 < 55° 的 session（2012-01-22/01-15）：目标 20% = 8.5-10.7°，**低于噪声底** → 抑制比 0.30-0.37 ❌
- **物理含义**：抑制比判据在低漂移 session 上"不可达"（不是估计器退化，是判据分母太小）
- **工程建议**：对低开环 session 应改用**绝对残差判据**（如融合 yaw ≤ 21.6° 固定阈值）——3 个 FAIL 的绝对残差 15.7-21.6° 全部落在健康区间内

### 3.2 PASS/FAIL 结构（24/27）

| 模式 | session | 根因 | 分类 |
|---|---|---|---|
| 低开环漂移 + 噪声底 | 2012-01-22（42.5°）、2012-01-15（53.3°）、2012-11-17（103.7°） | 抑制比判据分母小 | **判据问题，非估计器缺陷** |
| 其余 24 个 | 开环 68.8-115.1° | 抑制比 0.093-0.197 | 健康 ✅ |

### 3.3 退化模式分类（位置域）

| 模式 | 代表 session | 机制 | 影响 |
|---|---|---|---|
| **A. RTK 质量差时段** | 2012-11-04（rtk95=54 m）、2013-02-23（rtk95=25 m）、2012-05-26（rtk95=9 m） | rtk_err 尖峰（198-229 m）→ sig_h 自适应膨胀 → 位置更新权重骤降 → 融合位置长时段漂移（数 km） | pos RMSE 420-840 m；**yaw/roll 不受影响**（14-18°/1-3°） |
| **B. 数据格式坏行** | 2012-09-28（零坐标行 + alt 基准） | fix≥3 但 lat/lon=0 → to_enu 数千 km；首行 alt=nan → alt0=0 | pos RMSE 109,795 m → **修复后 77.7 m** |
| **C. 健康基线** | 2013-01-10、2012-04-29（rtk95 3.6-6 m） | RTK 质量好 | pos 7-15 m，yaw 6-11°（最佳 session） |

**关键结论**：位置退化与 RTK 质量强相关（corr(pos, rtk95) 显著），姿态残差对 RTK 质量**鲁棒**——因为 yaw 由航向伪观测约束（30 s 窗差分，天然平滑 RTK 噪声），roll/pitch 由速度更新约束。**融合估计器在 GNSS 失锁/降级场景下姿态保持稳定，位置随 RTK 质量成比例退化（有界、可恢复）。**

## 4. 工程改进（批处理驱动的两处修复）

1. **零坐标坏行过滤**：`if lat==0 or lon==0: continue`（NCLT 2012-09-28 起存在）
2. **基准行选择**：`i0 = first(fix>=3)` 替代固定第 0 行（alt0 不再被 fix<3/nan 行污染）
3. **rtk_err 过滤**：nan/≤0/>1000 m 剔除（防 sig_h 被 6.3e6 m 极端值污染）

修复效果：2012-09-28 pos RMSE **109,795 m → 77.7 m**（评估端污染消除），batch max 840 m。
