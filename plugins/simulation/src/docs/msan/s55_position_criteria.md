## 二、位置域判据定义（v1.0）

### 多级边界

```
PASS  if  pos_rmse < 200 m
WARN  if  200 m <= pos_rmse < 400 m
FAIL  if  pos_rmse >= 400 m
```

### 设计依据

| 边界 | 分布依据 | 语义 |
|---|---|---|
| PASS < 200 m | p75=180.27m 以下为健康主体 | 融合位置可用（厘米级 RTK fix 时段主导） |
| WARN 200-400 m | p90=344/p95=419 之间的过渡带 | 存在显著差时段/系统性偏移，可接受但需报告 |
| FAIL ≥ 400 m | 仅 2 个 session（419/444m） | 位置域明确不可用，必须调查 |

### WARN/FAIL 强制报告要求

- **WARN**：报告必须说明主要贡献因素（RTK 差时段 vs 系统性偏移），并引用
  `n_downweight_events` / `dr_hold_total_s` 佐证
- **FAIL**：触发系统性偏差检查流程（S52 边界规则 §3 同类处理）——区分随机噪声
  （门控可治）与系统性偏差（门控不可治，S54 02-23 案例），并列入调查项
- **边缘规则**：`pos_rmse` 与边界差 < 5 m 时，标注"边缘"并强制报告该 session 的
  RTK 质量指标（fix3% / rtk_err p95），由审阅者确认

## 四、回测对比：v3 vs legacy（T2 验收）

### 4.1 位置域分级对比

| 级别 | v3 (S54) | legacy (S51) | 变化 |
|---|---|---|---|
| PASS | 21/27 | 18/27 | **+3** ✅ |
| WARN | 4/27 | 6/27 | -2 |
| FAIL | 2/27 | 3/27 | **-1** ✅ |

legacy 的 3 个 FAIL：05-26 (840.6m), 11-04 (419.5m), 02-23 (443.9m)
v3 的 2 个 FAIL：11-04 (419.1m), 02-23 (443.8m)
→ **05-26 从 FAIL 升为 PASS（840.6→22.4m），S54 优化直接转化为判据 PASS 数提升**

### 4.2 双域组合（姿态域 v2 AND 位置域非 FAIL）

| 判定 | v3 | legacy | 变化 |
|---|---|---|---|
| PASS | 24/27 (88.9%) | 23/27 (85.2%) | **+1** ✅ |
| FAIL | 3/27 | 4/27 | -1 |

v3 双域 FAIL 的 3 个：11-04（位置 FAIL）、02-23（位置 FAIL）、11-17（姿态边缘 FAIL 21.63°）
legacy 额外 FAIL：05-26（位置 FAIL）→ v3 修复

### 4.3 姿态域不受影响验证

双域判定中 v3 姿态部分与 S52 v2 完全一致（26/27 姿态 PASS，仅 11-17 边缘 FAIL）——
位置判据的加入**未改变任何姿态判定**，仅新增位置维度约束。✅
