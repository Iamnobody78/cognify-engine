## 2. 融合估计器设计（nclt_fusion_ekf.py）

### 2.1 状态与传播

- 状态：`(p, v, θ, bg, ba, s_z)` 共 18 维；右扰动误差状态（Solà 约定）
- 误差转移关键项：
  - `F[3:6,6:9] = -Rq @ ab_sk`（姿态误差 → 速度误差耦合）
  - `F[3:6,15:18] = +Rq @ diag([0,0,a_b[2]])`（z 尺度误差 → 速度误差，符号经实验标定）
- 地球自转：`om = gyro - bg - R(q).T @ w_ie_n`（**体坐标系**地球自转，早期帧错误已修正）
- 加速度：`a_b = -(acc - ba)`（ms25 输出负比力，静止 acc_z = -9.8 需取反）

### 2.2 量测与鲁棒化

| 量测 | 频率 | 模型 | 鲁棒化 |
|---|---|---|---|
| RTK 位置（ENU） | 2 Hz | H = I 位置行 | 水平 2σ Huber（无硬门限） |
| RTK 位置（垂直） | 2 Hz | H = 单行 p_d | **Huber 3σ 膨胀（S50 修复，无硬门限）** |
| 速度标量 \|v\| | 事件 | RTK 速度差分 | 2σ Huber |
| 窗内速度（30 s 差分，kind=2） | 事件 | H = I 速度行 | 2σ Huber |
| **航向伪观测（kind=3）** | 事件 | H = Rq[2,:]（直接 yaw） | **机动自适应 σ + 创新 Huber** |

### 2.3 S50 关键修复（本 Sprint 因果推理产物）

1. **垂直 50 m 硬门限 → Huber 3σ 膨胀（决定性修复）**
   - 失败模式：急弯航向滞后 → yaw ±46~49° 扰动 → roll/pitch 污染 → 重力泄漏 → v_z 被踢至
     ~+19 m/s；旧 50 m 硬门限一旦被超过即**永久关闭**垂直校正 → p_z 以 19 m/s 单调发散至 +25.5 km
   - 修复：垂直更新无硬门限，改用与水平一致的 Huber 膨胀（|innov|>3σ 时 R=(innov/3)²），
     既防大创新自泵（v_z 正反馈），又允许垂直在姿态恢复后重新锚定 RTK 高度
   - 实证：p_d 在 t=3100 s 瞬时 -198 m 后 **80 s 内自愈至 -3 m**；位置 RMSE 8772 m → **78.2 m**
2. **航向机动自适应 σ + 创新 Huber**
   - 30 s 窗差分航向在急弯处滞后（真值 197°/60s 摆幅 → ~50° 滞后偏差）
   - 修复 1：σ_hdg = 10° + 100°·max(0, |ω_z|−0.02 rad/s)（弯道降权）
   - 修复 2：创新 Huber（|innov|>3σ 时膨胀 R）——覆盖"弯道结束、|ω_z| 回落、过期窗航向以全强度
     撞击 yaw"的残留路径
   - 实证：弯道 yaw 扰动仍瞬时存在（±50°），但不再扩散为垂直发散

### 2.4 可观测性结论（本 Sprint 重要发现）

- 水平姿态与速度强耦合（f≈[0,0,g] → δv̇ = R·[9.8δθ_y, −9.8δθ_x, 0]），**位置/速度更新可观测 roll/pitch**
- **yaw 对位置与速度更新均不可观测**（δv̇ 无 δθ_z 分量）→ 必须引入航向伪观测（窗差分 + 非完整约束）
- z 尺度误差（ms25 ~0.5-0.7%）垂直方向必须建模为状态；x/y 尺度与水平 ba 纠缠，冻结处理

## 3. 外部数据源前置可行性探测（methodology）

**背景**：PM T1 原指令为"GICI spp_imu 配置适配（SPP+IMU 紧耦合，NCLT 真实 IMU 输入）"。

### 3.1 可行性探测流程（前置，先于任何适配工作）

```
1. 格式探针（源码级）：GICI NmeaFormator::decode() → "NMEA decoding not supported!"
   → GICI 无位置域/NMEA 输入格式化器（纯输出），全部估计器需原始 tersus 观测
2. 数据源探针：NCLT 提供后处理位置解（无 RINEX/tersus 原始观测）
   Oxford/KITTI 同（无原始载波相位）
3. 配对探针：IGS BRDC 广播星历可下载但与 NCLT 历元无配对观测文件 → 无法做 SPP 求解
4. 结论：GICI 原生 SPP+IMU 紧耦合 = 不可行（数据供给缺口，非代码缺陷）
```

### 3.2 等价替代路径（如实标注，非 GICI 原生）

- **位置域 EKF 融合**：相同的物理目标（真实 IMU 零偏/随机游走/尺度误差 + RTK 位置约束），
  不同实现载体（自有 EKF 替代 GICI 估计器）
- 全程**全真实数据**：真实 IMU + 真实 RTK 位置 + 真实姿态真值（ms25_euler）
- 三段式对比以"抑制比"度量融合效果，与 GICI 原生路径的评价框架一致
- 已在 metrics note 与 PM 汇报中**明确标注**："position-domain EKF = equivalent closed-loop
  fusion with all-real data"，不冒充 GICI 原生结果

### 3.3 方法论沉淀（可复用）

| 步骤 | 动作 | 本 Sprint 实例 |
|---|---|---|
| A | 源码级能力探针（不假设，读代码） | NmeaFormator 输出唯一性确认 |
| B | 数据格式与列索引双重校验（写独立验证脚本） | NCLT gyro=cols 7-9、acc=4-6；gps_rtk 已为弧度 |
| C | 单位/符号自检（数学约定 vs 传感器输出） | ms25 负比力取反；radians 双重转换 bug 实证（1e-5°→1.11 m） |
| D | 可观测性分析（先于调参） | yaw 不可观测 → 必须航向伪观测 |
| E | 鲁棒更新优先于参数调优 | Huber 无硬门限 vs 50 m 硬门限（决定性差异） |
| F | 失败轨迹因果链文档化 | 见 failure_analysis.md / 本报告 §2.3 |
