## 一、否决结论

> **在当前数据供给条件下，GICI 原生 SPP+IMU 紧耦合路径（启用 `SppImuTc` 估计器 + 真实 IMU 输入）
> 不具备启动条件，且当前位置域 EKF 融合路径已充分满足工程目标，故正式否决原生路径改造。**

否决类型：**实证否决**（非能力否决）——不是"做不了"，而是"证据链显示投入产出不匹配"。

## 二、证据链（S50 → S51 → S52 三阶段）

### 1. 可行性阻断（S50 T1，源码级证据）

| 阻断点 | 证据 | 结论 |
|---|---|---|
| GICI 无位置域输入格式化器 | `NmeaFormator::decode()` 返回 "NMEA decoding not supported!"（输出唯一） | 所有估计器需原始 tersus 观测 |
| NCLT/Oxford/KITTI 无原始观测 | 仅提供后处理位置解（无 RINEX/tersus 原始载波相位） | 数据供给缺口 |
| IGS BRDC 无配对 | 广播星历可下载但与历元无配对观测文件 | 无法做 SPP 求解 |

→ 原生路径 = **数据供给缺口**，非代码缺陷。当时即采用"位置域 EKF 等价替代"（如实标注，不冒充原生）。

### 2. 充分性验证（S51 T2，27-session 批处理）

| 指标 | 值 | 判定 |
|---|---|---|
| 27/27 session 成功运行 | 100% | ✅ |
| PASS 率（v1 单判据） | 24/27 = 88.9% | ✅ |
| 融合 yaw RMSE | mean 16.0° · med 16.4° · std 2.9°（CV=18%） | 跨 session 高度可重复 |
| 抑制比 | mean 0.170 · med 0.156 | 稳定 |
| 位置 RMSE | med 124.5 m · max 840.6 m（RTK 差时段） | 有界 |
| 姿态对 GNSS 降级鲁棒性 | RTK 差时段 yaw/roll 全程健康 | ✅ |

→ 当前 EKF 路径已证明**足够稳健、跨 session 一致**。

### 3. 判据演进确认（S52 T2，双判据回测）

| 判据 | PASS 率 | 说明 |
|---|---|---|
| v1 单判据（抑制比<0.20） | 88.9% | 3 个 FAIL 中 2 个为判据不可达 |
| v2 双判据（+绝对残差≤21.6°） | **96.3%** | 仅 2012-11-17 边缘 FAIL（真实退化） |

→ 判据问题也已解决，位置域路径无剩余缺口需要原生路径填补。

## 三、否决理由汇总

| # | 理由 | 维度 |
|---|---|---|
| 1 | **数据供给缺口**：无原始观测 → 原生路径无输入（S50 源码级确认） | 可行性 |
| 2 | **成本不对称**：GICI 源码级改造 + 数据格式适配 vs 位置域 EKF 已验证 | 成本 |
| 3 | **收益不明确**：27-session 一致性已达标，原生紧耦合的预期增益（厘米级位置）超出当前评估目标（姿态残差 + 有界位置） | 收益 |
| 4 | **风险**：原生路径无 NCLT 可直接消费的数据，验证链需重建（S47-S51 全部重做） | 风险 |
| 5 | **PM 裁决支撑**：裁决 2 明确"当前 EKF 路径已足够稳健，跨 session 一致性高度可重复" | 治理 |

## 四、条件性重启条件（若未来触发）

若出现以下任一条件，可重新评估原生路径：

1. **新数据供给**：获得含原始 RINEX + tersus 观测的配对数据集（自采或新公开数据集）
2. **新工程目标**：位置精度要求升至厘米级（RTK 原始观测融合），超越当前"有界位置 + 姿态残差"目标
3. **GICI 上游更新**：官方新增位置域/NMEA 输入支持，降低改造成本

重启时建议路径：`feature/s50_spp_imu` 分支的阻断证据文档 + 本文档作为起点，评估新数据格式兼容性。
